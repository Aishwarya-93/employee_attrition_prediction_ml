# Employee Attrition Prediction using Machine Learning

Overview
This project is a Machine Learning-based Employee Attrition Prediction System developed using Python and Streamlit.  
The model predicts whether an employee is likely to leave an organization based on demographic, professional, and workplace factors.

The system is designed to assist HR teams in identifying high-risk employees and taking proactive retention measures.

---

Objectives
- Analyze employee data to identify attrition patterns
- Build a robust ML model for attrition prediction
- Deploy the model using an interactive Streamlit web application
- Provide decision-support insights for HR departments

---

Machine Learning Approach
- Problem Type: Binary Classification
- Algorithms Used:
  - Logistic Regression
  - Random Forest
  - **XGBoost (Final Model)**
- Class imbalance handled using SMOTE
- Model evaluation using Accuracy, Recall, F1-score, and Confusion Matrix

---

Tech Stack
- Programming Language: Python
- Libraries: Pandas, NumPy, Scikit-learn, XGBoost
- Visualization: Matplotlib, Seaborn
- Web Framework: Streamlit
- Model Persistence: Joblib

---

Features Used
- Age, Monthly Income, Job Level
- Job Satisfaction, Work-Life Balance
- OverTime, Years at Company
- Department, Job Role, Education Field
- Business Travel, Marital Status
- And other HR-related attributes

---

Application Features
- Interactive web-based GUI
- Real-time attrition risk prediction
- Probability score for attrition
- Input validation for realistic HR data
- Model trained on real-world HR dataset
